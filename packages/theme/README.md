# @bc/theme

TC-style theme tokens — Segoe UI / Consolas, white-bg panels, blue cursor, red marked/hidden, light-blue (`#E5EFFE`) column headers. Standalone so `@bc/file-list` and `@bc/ui-rn` can both consume it without a workspace dependency cycle.

**Exports**
- `tcTheme` — readonly object: `font`, `color`.
- `TcTheme` — its inferred type.
